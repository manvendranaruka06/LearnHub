# 📚 LearnHub – Smart Study Resource Finder

## 🚀 Overview

LearnHub is a React-based web application that helps students discover useful learning resources in one place. Instead of searching across multiple platforms, users can simply enter a topic and get relevant YouTube videos and GitHub repositories instantly.

---

## 🎯 Objective

* To build a responsive web application using React
* To integrate public APIs and display real-time data
* To implement search, filtering, and sorting using JavaScript Higher-Order Functions
* To enhance user experience with features like favorites and dark mode

---

## ✨ Features

### 🔍 Core Features

* Search study topics (e.g., React, DSA, Web Development, etc.)
* Fetch real-time data from public APIs
* Filter results based on level (Beginner / Advanced)
* Sort resources by popularity or views
* Save favorite resources using localStorage
* Toggle between Dark Mode and Light Mode

### ⚡ Bonus Features

* Debounced search for better performance
* Pagination / Infinite scrolling
* Fully responsive design

---

## 🔌 APIs Used

* YouTube Data API – for fetching study videos
* GitHub API – for fetching repositories and projects

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* Fetch API
* LocalStorage

---

## 🧠 How It Works

1. User enters a topic in the search bar
2. The app fetches data from YouTube and GitHub APIs
3. Results are displayed in a card-based UI
4. Users can filter, sort, and save resources

---

## 📊 Use of JavaScript HOFs

* `map()` → for rendering data
* `filter()` → for search and filtering
* `sort()` → for sorting results
